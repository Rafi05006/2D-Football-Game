# 2D Football Game

A two-dimensional football game built with C/C++, iGraphics, and bitmap assets. The game includes a menu, goalkeeper interactions, scoring, and local two-player gameplay.

## Requirements

- Visual Studio on Windows
- iGraphics and the WinMM library

## Run

Open the project in Visual Studio with the source files, `iGraphics.h`, DLLs, and the `pic/` asset directory in the same project folder. Build and run the project.
